# Статические файлы

Эта папка содержит статические файлы приложения:

## Структура

- `uploaded_photos/` - фотографии, загруженные пользователями
  - Файлы сохраняются с уникальными именами
  - Автоматически очищаются при удалении записей из БД

- `generated_images/` - сгенерированные изображения
  - Картины по номерам
  - Превью изображения
  - Нумерованные версии

## Безопасность

- Все загружаемые файлы проходят валидацию
- Изображения проверяются на наличие вредоносного кода
- Ограничения по размеру и формату

## Резервное копирование

Рекомендуется настроить регулярное резервное копирование этой папки.
