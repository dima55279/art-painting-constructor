# Веб-приложение проекта ArtPaintingConstructor

Для запуска приложения на локальном сервере необходимо:

1. Установить [node.js](https://nodejs.org/en/download) на свой компьютер.

2. Склонировать данный репозиторий: `git clone https://github.com/dima55279/art-painting-constructor.git`

3. Перейти в директорию репозитория и установить все необходимые зависимости: `npm install`

4. Запустить веб-приложение: `npm start`
