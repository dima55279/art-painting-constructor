# Веб-приложение проекта ArtPaintingConstructor

## Для запуска веб-приложения необходимо:

1. Склонировать данный репозиторий: `git clone https://github.com/dima55279/art-painting-constructor.git`

2. Для запуска клиентской (фронтэнд), серверной (бэкэнд) частей и Stable Diffusion выполнить следующие действия:

### Для запуска клиентской части (фронтэнд) на локальном сервере необходимо:

1. Установить [node.js](https://nodejs.org/en/download) на свой компьютер.

2. Перейти в директорию репозитория и установить все необходимые зависимости: `npm install`

3. Запустить клиентскую часть: `npm start`

### Для запуска серверной части (бэкэнд) на локальном сервере необходимо:

1. Установить [cmake](https://cmake.org/download) на свой компьютер.

    * Выберите Windows x64 Installer.

    * Важно: При установке отметьте галочку "Add CMake to the system PATH for all users".

2. Установить [MySQL](https://dev.mysql.com/downloads/installer) на свой компьютер.

    * При установке необходимо установить все модули СУБД, которые предлагает установщик.

3. Перейти в директорию `server`, открыть отдельный терминал от клиентской части и установить все необходимые зависимости: `pip install -r requirements.txt`

    * Библиотеки занимают много памяти, а их установка и загрузка может занять определённое время

4. До первого запуска серверной части необходимо инициализировать миграцию базы данных: `python.exe init_db.py`

5. До первого запуска серверной части необходимо инициализировать миграцию базы данных: `python.exe migrations/manage_migrations.py migrate`

6. До первого запуска серверной части необходимо загрузить рамки в базу данных: `python.exe update_frames.py`

7. Запустить серверную часть: `uvicorn app.main:app --reload --host 0.0.0.0 --port 8000`

### Для запуска Stable Diffusion на локальном сервере необходимо:

1. Скачать архив с нейросетью из Google Drive (ссылка на архив не у меня), разархивировать, директорию `stable-diffusion-webui` перенести в корень проекта.

2. Зайти в директорию `venv`, отредактировать файл `pyvenv.cfg`, поместив в параметр `home` путь системной переменной к Python.

3. Запустить из директории `stable-diffusion-webui` Stable Diffusion: `./webui.bat --api --cors-allow-origins=http://localhost:3000`
